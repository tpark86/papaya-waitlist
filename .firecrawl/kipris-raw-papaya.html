    특허 시각화 기능 `특허뷰` 제공 안내
    특허 시각화 기능 특허뷰 제공 안내 특허 시각화 기능이 아래와 같이 추가되어 안내드립니다.새롭게 추가된 기능을 통해 특허의 진행 경과, 행정 흐름, 기술분류 및 패밀리 관계를직관적으로 확인 하실 수 있습니다.특허 타임라인 제공 - 출원, 공개, 심사청구, 등록 및 거절 등 특허의 주요 진행 이력을 시간 순으로 확인할 수 있습니다.통합행정정보 타임라인 제공 - 상세정보에서 제공하는 특허의 통합행정정보를 시간 순으로 제공하여 시간 흐름에 따른 행정정보를 확인할 수 있습니다.인용·피인용·패밀리 정보 분석 - 해당 특허와 연관된 인용, 피인용 및 패밀리 정보를 시각적으로 제공하여 특허 간 연관 계를 파악할 수 있습니다.피인용의 CPC / IPC 분류 정보 제공 - 특허의 기술 분류 정보를 차트 형태로 제공하여 주요 기술 분야 및 분포를 확인할 수 있습니다.패밀리 네트워크 시각화 - 국가별 특허 패밀리 관계를 네트워크 형태로 제공하여 현재 출원과 관련된 특허 현황을 종합적으로 파악할 수 있습니다.패밀리 지도 제공 - 국가별 패밀리 특허를 지도로 제공하여 해당 패밀리의 국제 현황을 쉽게 확인할 수 있습니다.앞으로도 서비스 제공을 위해 지속적으로 노력하겠습니다.감사합니다!
    검색도움말 개선 안내
    검색 도움말 개선 안내안녕하십니까? 검색 도움말이 개편되어 안내드립니다.복잡했던 도움말을 최신 정보 위주로 재정비하고 툴팁과 모달 등 편의 기능을 더해,사용자 중심의 직관적인 안내 서비스로 개편하여 안내드립니다.1. 용어 설명 및 검색 방법, 서비스 이용방법 안내 툴팁 추가사용자가 행정상태 등 생소한 용어에 대한 설명과 항목별 검색 방법, 서비스 이용방법을 빠르게 확인할 수 있도록 툴팁을 추가하였습니다.2. 단계별 가이드 제공사용자가 원하는 도움말 항목을 단계적으로 쉽게 찾을 수 있도록 '도움말 찾기' 기능을 추가하였습니다.3. 화면 구성 및 가독성 개선글자 위주의 복잡한 설명을 줄이고, 이미지와 설명을 보기 좋게 배치하여 쉽게 내용을 이해할 수 있도록 개선하였습니다.앞으로도 서비스 제공을 위해지속적으로 노력하겠습니다.감사합니다!

    항목 연산자 안내
    • AND : 모든 조건을 만족하는 경우 검색
    • 예) 내용검색(발명의 명칭) 칸에 "자동차", 인명정보(출원인) 칸에 "홍길동" 입력 후 AND로 검색 시
    • → 발명의 명칭이 "자동차"고 출원인이 "홍길동" 둘 다 만족하는 특허를 확인할 수 있습니다.
    • OR : 조건 중 하나 이상을 만족하는 경우 검색
    • 내용검색(요약) 칸에 "스마트폰", 분류정보(IPC) 칸에 "G06Q" 입력 후 OR로 검색 시
    • → 요약이 "스마트폰"이거나 IPC가 "G06Q" 둘 중 하나라도 만족하는 특허를 확인할 수 있습니다.
    키워드 연산자 안내
    • * : 모든 조건을 만족하는 경우 검색
    • 예) 자유검색(전문)에 "물*순환"으로 검색 시
    • → 모든 내용에서 "물"과 "순환"이 모두 들어간 특허를 확인할 수 있습니다.
    • + : 조건 중 하나 이상을 만족하는 경우 검색
    • 예) 청구범위 칸에 "탄소+저감"으로 검색 시
    • → 청구범위에 "탄소"나 "저감" 중 하나라도 들어가는 모든 특허를 확인할 수 있습니다.
    • ! : 특정 키워드가 포함된 문헌을 결과에서 제외
    • 예) 상표명칭 칸에 "사랑?*!열매"으로 검색 시
    • → "상표명칭"에 "사랑"을 포함하고 "열매"를 포함하지 않는 검색결과를 확인할 수 있습니다.
    • ^ : 두 키워드가 서로 일정한 거리(단어 수) 안에 위치하는 경우를 검색
    • 예) "발명의명칭" 칸에 "바퀴^2각도"를 입력
    • → "발명의 명칭"에 "바퀴" 뒤 두 번째 단어 이내에 "각도"가 있는 검색결과를 확인할 수 있습니다.
    • ? : ? 는 일부를 생략하여 검색
    • 예) "상표명칭" 칸에 "사랑?"을 입력
    • → "상표명칭"에 "사랑"으로 시작하는 검색결과를 확인할 수 있습니다.
    • 연산자와 관련된 자세한 설명은 연산자 사용방법에서 확인할 수 있습니다.

    CPC Code & Content
    • Advanced Patent Classification (CPC) Code

      CPC (Cooperative Patent Classification) is a more detailed patent classification system than IPC (International Patent Classification), and has more than 260,000 patent classification locations, more than IPC (70,000 locations).
      CPC was developed in 2012 led by the US Patent Office and the European Patent Office for efficient prior art investigation.
      Currently, about 30 countries around the world classify patent literature as CPC, and more than 60 million documents around the world, including patent and non-patent literature, are classified as CPC.
      Korea has been granting CPC and IPC to new applications since January 2015.

    USPC Code & Content
    • U.S. Patent Classification (USPC) Code

      USPC (United States Patent Classification) is an independent patent classification used by the US Patent and Trademark Office with IPC (International Patent Classification).
      USPC was a code for classifying inventions as a patent classification system used by the United States since 1831, before the creation of IPC, and is classified in terms of application field, function, effect, and structure.
      USPC is classified based on claims, so it is different from IPC, which is classified in terms of technology related to invention, and if IPC is based on industrial classification, USPC can classify them based on functions and obtain more accurate search results during prior technology investigations.

      ※ Currently, it is replaced by CPC (Collaborative Patent Classification)

    ECLA Code & Content
    • European Patent Classification (ECLA) Code

      European Classification (ECLA) is an independent classification used by the European Patent Office (EPO) and is used with IPC (International Patent Classification).
      ECLA is a more subdivided IPC and is a similar concept to Japan's FI, but it is given not only to European patents but also to patent literature in the United States, Japan, and Korea, which is different from Japan's FI, F-Term, or UPC in the United States, which only gives its own patent literature.
      IPC was first implemented in 1968, and IPC was not listed in the patent document before that, but ECLA began to be used in the 1920s, so it can be useful for searching old patent documents (before 1968) as ECLA is also listed in patent documents before 1968.
      ※ Currently, it is replaced by CPC (Collaborative Patent Classification)

    • Japanese Reader Classification (FI) Code

      The File Index (FI) is designed to efficiently conduct patent investigations by imposing development symbols and divisional identification symbols on IPC to further subdivide specific IPC as a technical field that is difficult to investigate with only IPC occurs because a large amount of patent literature is concentrated on a specific IPC due to Japan's technological situation, for example, Japan's unique technology or advanced technology compared to other countries.

    • F-Term Code

      File Forming Term (F-Term) is a search index developed for computer search to conduct prior technology research in the examination in response to the remarkable increase in patent literature and the trend of modern technology development that is becoming more complex, convergence, and product diversification.
      F-Term is a re-classification or subdivision of FI from various technical perspectives for each given technology field, and if you select a theme code that corresponds to the technology perspective and use the technology perspective and technology development such as purpose, purpose, structure, material, manufacturing, processing method, and control means, the search is conducted in various forms, and if you combine these perspectives to conduct an investigation, it is possible to approach the technology topic to be investigated from multiple perspectives, so F-Term can be very useful in Japanese patent search.
